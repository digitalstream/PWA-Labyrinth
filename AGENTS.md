# Working with this project

## Git and GitHub learning preference

The user wants to run Git and GitHub CLI commands personally to learn.
Explain each command and provide PowerShell commands in small steps, then
wait for the user's results before continuing. Do not run Git/GitHub CLI
commands, create commits, or push on their behalf unless they explicitly
ask you to execute the commands for them. Source edits and ordinary file
inspection can continue normally when authorised.
